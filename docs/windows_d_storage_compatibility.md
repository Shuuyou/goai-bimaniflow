# 数据分区文件系统兼容性测试（fuseblk 探针，历史记录）

日期：2026-08-12。测试目录已完整删除，未触碰其他文件。
注：2026-08-16 起项目大文件已迁至 ext4 /data 分区，本文件为历史存档。

## 探针结果（均为实际命令输出）

| 测试 | 结果 |
|---|---|
| 普通文件创建/读取/删除 | OK |
| 子目录创建/删除 | OK |
| 文件重命名 / 原子 rename | OK |
| 大小写文件名共存 | 可同时存在（挂载语义，不依赖） |
| chmod | **不生效**（一律 777） |
| 符号链接 / 硬链接 | 支持 |
| 文件所有权 | 一律 `root:root 0777`（挂载语义） |
| flock（shell 与 Python fcntl） | 均 OK |
| 1 MB 稀疏文件 | 支持 |
| 1 MB 普通文件写入 | 约 373 MB/s（单次小样本） |

## 结论

| 用途 | 是否适合 |
|---|---|
| 大文件冷存储 / 模型权重 / HDF5 / 视频日志 | 适合 |
| 高频随机写（zarr 训练缓存等） | **不建议**（INFERENCE） |
| Git 工作树 / Conda 环境 / Docker overlay2 / Isaac Sim 核心环境 | **不适合** |
| 只读挂载进容器（`-v ...:ro`） | 适合 |
