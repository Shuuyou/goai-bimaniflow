# Phase 4A 外部连通性测试

前置：测试必须从服务器之外发起；不得从本机访问自己的公网地址充数；不得用真实 X-Eval 表单测试。

## 待验证清单

1. DNS 解析（外部机器）
2. TLS 证书链（若启用 wss）
3. ws/wss 握手
4. HELLO / HEARTBEAT / PREPARE_CASE / RESET / 至少一次合成 INFER / CLOSE
5. 断线重连
6. 重复 request ID 重放
7. 空闲连接保活 ≥25 分钟
8. 服务端无连接/内存/显存泄漏
9. 端到端延迟 P50/P95/P99

## 已完成的实测（2026-08-20 晚，云主机 47.101.158.121）

- 部署形态：阿里云轻量服务器 47.101.158.121（sshd GatewayPorts=clientspecified）← SSH 反向隧道（ServerAlive 保活 + watchdog 自重启 scripts/phase4a_tunnel_watchdog.sh）← 127.0.0.1:6061 ACT v1（冻结配置）。
- 云端本地 `curl 127.0.0.1:8443` → 426（隧道通）；云端 `curl 47.101.158.121:8443` → 426（阿里云防火墙放行后公网 IP 通）。
- 经公网端点的协议回归（本机作为客户端，ws://47.101.158.121:8443）：HELLO/PREPARE_CASE/RESET/100×INFER（全部有限、契约一致）/CLOSE 全通过，EXIT=0。延迟 P50 1609 / P95 2465 / P99 3116 ms —— 该数值受**本机上行带宽**主导（msgpack 原始观测 ~2.8 MB/步 上传）；正式评测数据方向相反（观测下行到本机、动作 KB 级上行），预计远好于此。如实标注：这是本机发起的公网回路测试，**最终外部证明需用户手机/外部机器确认**。
- 待外部确认项：手机 5G `curl http://47.101.158.121:8443/` 返回 426；25 分钟空闲保活；断线重连；端到端延迟（外部客户端视角）。
